# Cognida UI 重新设计方案

## 一、美学定位：「工业数据终端」

### 设计理念
Cognida 是一个智能数据系统，UI 应该传达**精确性、专业性、可靠性**。选择工业终端美学，创造一个让数据工作者感到熟悉且专业的界面。

**核心关键词**：
- 精确
- 专业
- 高效
- 可信

---

## 二、配色系统

### 主色调
```
背景层级：
--bg-deep:      #08080a    // 最深背景
--bg-surface:   #0d0d10    // 主表面
--bg-elevated:  #131318    // 浮起元素
--bg-input:     #1a1a21    // 输入框背景

文字层级：
--text-primary:   #e8e8ec   // 主要文字
--text-secondary: #a0a0b0   // 次要文字
--text-muted:     #606070   // 弱化文字
--text-dim:       #404050   // 极弱文字
```

### 强调色（单一主色，避免花哨）
```
--accent-primary:   #f59e0b   // 琥珀色 - 温暖、醒目、不常见
--accent-hover:     #fbbf24   // 悬浮态
--accent-active:    #d97706   // 激活态

语义色：
--color-success:    #10b981   // 绿色
--color-warning:    #f59e0b   // 使用主色
--color-error:      #ef4444   // 红色
--color-info:       #3b82f6   // 蓝色
```

### 边框与分割
```
--border-subtle:    rgba(255,255,255,0.06)
--border-default:   rgba(255,255,255,0.10)
--border-strong:    rgba(255,255,255,0.16)
--border-accent:    rgba(245,158,11,0.50)
```

## 三、字体系统

### 主字体：IBM Plex Mono
```
--font-primary: 'IBM Plex Mono', 'SF Mono', 'Consolas', monospace
--font-secondary: 'IBM Plex Sans', system-ui, sans-serif
```

**为什么选择等宽字体**：
- 数据系统需要精确的字符对齐
- 传达专业/技术感
- 与众不同的视觉特征

### 字号阶梯（使用 rem 单位）
```
--text-xs:   0.75rem   // 12px - 标签、辅助
--text-sm:   0.875rem  // 14px - 次要文字
--text-base: 1rem      // 16px - 正文
--text-lg:   1.125rem  // 18px - 小标题
--text-xl:   1.25rem   // 20px - 标题
--text-2xl:  1.5rem    // 24px - 大标题
--text-3xl:  2rem      // 32px - 页面标题
--text-4xl:  2.5rem    // 40px - 品牌名
```

### 字重
```
--font-regular:  400
--font-medium:   500
--font-semibold: 600
--font-bold:     700
```

## 五、组件设计规范

### 按钮（BaseButton）

**设计原则**：明确的功能区分，微小的装饰细节

```
Primary（主按钮）：
- 琥珀色背景 (#f59e0b)
- 深色文字 (#0a0a0a)
- 右上角小三角装饰
- Hover：亮度提升

Secondary（次要按钮）：
- 透明背景
- 琥珀色边框
- 琥珀色文字
- Hover：填充琥珀色背景

Ghost（幽灵按钮）：
- 完全透明
- 灰色文字
- Hover：文字变亮 + 下划线

Tech（技术按钮，特色）：
- 类似代码标签的样式
- 等宽字体
- 小型方括号装饰 [ BUTTON ]
```

### 卡片（BaseCard）

**设计元素**：
```
结构：
┌────────────────────────────────┐
│ ▶ HEADER       ···  [METADATA] │ ← 装饰线
├────────────────────────────────┤
│                                │
│           CONTENT              │
│                                │
└────────────────────────────────┘
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │ ← 底部装饰
```

**特色细节**：
- 左侧彩色条（状态指示）
- 角标装饰（右上角小方块）
- 扫描线效果（hover 时）
- 技术参数角标（如 v2.0、BETA）

### 输入框（BaseInput）

**终端风格**：
```
┌─────────────────────────────┐
│ > ENTER_DATA...             │ ← 提示符
└─────────────────────────────┘
│ [█]                         │ ← 光标
```

**状态指示**：
- 默认：灰色边框
- 聚焦：琥珀色边框 + 光标闪烁
- 错误：红色边框 + 错误图标
- 成功：绿色边框 + ✓ 图标

## 六、视觉特效

### 微动效
```
 Fade In:    元素入场 200ms
 Slide Up:   上滑入场 250ms
 Scale In:   缩放入场 150ms
 Cursor:     光标闪烁 1s 无限
 Scan:       扫描线 3s 单次（hover）
```

### 装饰元素
```
1. 网格背景：细线网格，密度 40px
2. 扫描线：水平线，从上到下移动
3. 数据点：随机分布的小方块
4. 角标：技术感的 [ ] 标记
5. 分隔线：虚线或点线
```

### 加载状态
```
Spinner:      方形旋转（不是圆形）
Progress:     实心进度条，琥珀色
Skeleton:     闪烁的灰色块
```

## 八、色彩对比度

所有文字与背景对比度符合 WCAG AA 标准：
- 正常文字（14px+）：对比度 ≥ 4.5:1
- 大文字（18px+）：对比度 ≥ 3:1

当前配色实测对比度：
- #e8e8ec on #0d0d10 ≈ 15.2:1 ✓
- #a0a0b0 on #0d0d10 ≈ 8.1:1 ✓
- #f59e0b on #0d0d10 ≈ 6.8:1 ✓

**方案总结**：

这是一个**克制、专业、有记忆点**的设计系统：
- 抛弃常见的紫粉渐变，选择少见的琥珀色
- 抛弃 Inter，选择等宽的 IBM Plex Mono
- 抛弃圆润，选择精确的几何线条
- 抛弃装饰性，强调功能性

整个设计传达一个核心信息：**Cognida 是一个专业的数据操作系统**。
