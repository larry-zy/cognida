
### 使用规则

| 场景 | 字体 | 示例 |

## 九、对比度检查

| 组合 | 对比度 | 标准 | 状态 |
|------|--------|------|------|
| #f0f0f5 / 背景(0%遮罩) | ~17:1 | 4.5:1 | ✓ |
| #f0f0f5 / 背景(65%遮罩) | ~16:1 | 4.5:1 | ✓ |
| #b0b0c0 / 背景(65%遮罩) | ~9:1 | 4.5:1 | ✓ |
| #ff6b35 / 背景 | ~5:1 | 3:1 | ✓ (大文字可用) |
| #ff6b35 按钮(白字) | ~5.2:1 | 4.5:1 | ✓ |

---

**设计原则总结**：

1. **深色基调**：与背景图融合，营造专业感
2. **橙色强调**：呼应背景光效，传达活力与行动
3. **玻璃态**：让背景图适度透出，增强层次
4. **克制使用**：颜色和特效都有明确目的，不花哨
5. **可读优先**：确保所有文字足够清晰
