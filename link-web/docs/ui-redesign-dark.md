# Link UI 暗色调设计方案

## 设计理念

**纯粹暗色系** - 克制、专业、数据聚焦

> 去除彩色强调，使用灰白层级营造层次感

## 八、实施优先级

```
Phase 1: global.css + 基础变量
Phase 2: BaseButton + BaseCard + BaseInput
Phase 3: Login + Home + Chat 页面
Phase 4: BaseModal + BaseTag + BaseSidebar
Phase 5: 动画 + 响应式 + 细节
```

---

**设计原则**：

1. **纯暗色调**：无彩色强调，克制专业
2. **灰白层次**：用透明度区分层级
3. **边框主导**：精细的边框控制层次
4. **低饱和度**：语义色保持低调
5. **可读优先**：高对比度确保清晰
