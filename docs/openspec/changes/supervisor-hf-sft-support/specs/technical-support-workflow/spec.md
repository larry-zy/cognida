## ADDED Requirements

### Requirement: Real technical support acceptance
Acceptance MUST execute actual browser, HTTP, database, file decoder and knowledge retrieval operations for a bounded technical support and troubleshooting scenario.

#### Scenario: Data to audited SFT and usable knowledge
- **WHEN** fixed public support data is collected, cleaned, prepared and bound to standards
- **THEN** task receipts identify each stage, SFT is manually reviewed and exported, knowledge can be retrieved with sources, and an Agent can answer or analyze the scenario with inspectable evidence.

### Requirement: Preserve independent capability evidence
Acceptance SHALL also execute independent HF import or readback and standalone SFT/prepare/standard flows and retain both failures and final results.

#### Scenario: Complete verification and cleanup
- **WHEN** implementation finishes
- **THEN** core, real database/API, browser and independent Review results are recorded, and task-owned services and test resources are cleaned before completion.
