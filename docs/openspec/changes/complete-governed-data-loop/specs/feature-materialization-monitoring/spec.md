## ADDED Requirements

### Requirement: 不可变特征计算定义
特征定义 SHALL 支持 field、受限 expression、window_aggregate 和 embedding，并固定输入版本、算子、参数及输出类型；MUST 校验来源权限和类型，保留精确原值，向量特征绑定真实模型及修订，不以随机或哈希向量替代语义模型。

#### Scenario: 特征定义或模型发生变化
- **WHEN** 用户修改计算表达式、窗口参数或 embedding 模型修订
- **THEN** 系统生成新的定义版本，已有物化值继续绑定旧版本；缺少所需模型或来源授权时拒绝计算，不返回替代成功结果

### Requirement: 可恢复的分区物化
物化任务 SHALL 通过受限查询或有界分批 Worker 执行，保存分区、水位、输入版本和输出摘要；MUST 支持幂等重试、回填、撤回及跨特征批量读取，只有分区提交可核对后才推进水位，不把全表塞入 prompt 或静默截断为完整结果。

#### Scenario: 分区提交后进程重启
- **WHEN** 特征分区已写入，但任务在持久化完成回执前重启
- **THEN** 恢复过程按操作标识和摘要核对原分区，避免重复值或水位跳跃，未完成分区继续可见且不会覆盖其他版本

### Requirement: 双时间时点正确性
特征值 MUST 同时保留事件时间和可用时间，as_of 读取排除未来事件以及该时点尚不可用的事后补写数据；离线宽表、批量查询和分析 SHALL 使用同一版本定义及时间语义，不因回填改写已有评测快照。

#### Scenario: 历史事件延迟到达
- **WHEN** 事件发生于查询时点之前，但直到该时点之后才入库并完成物化
- **THEN** 历史 as_of 查询不包含该值，后续允许时点可读取它，历史评测快照及其手算预期保持不变

### Requirement: 真实基线漂移检测
漂移检测 MUST 使用固定真实参考快照或有记录的确定性采样，禁止按均值方差重建随机正态基线；SHALL 覆盖数值分布、类别频率、缺失率及 schema 变化，输出样本量、效应大小、统计方法、阈值和证据不足状态，不把 p 值解释为漂移概率。

#### Scenario: 非正态基线与不足样本
- **WHEN** 同一非正态真实基线被重复比较，或选定列缺失、有效样本不足
- **THEN** 相同输入和采样配置产生可复现结果；缺列和小样本明确报告变化或证据不足，不伪装成已经证实无漂移

### Requirement: 监控异常进入治理
监控 SHALL 关联基线版本、当前快照、比较报告及后续治理或补采任务，MUST 在读取、调度和恢复时复查来源权限；分布变化不得自动认定业务质量下降，更换基线或发布新特征版本必须经过相应审批并保留旧证据。

#### Scenario: 异常触发补采但审批未完成
- **WHEN** 检测到分布变化并生成补采或重算建议，而基线更新尚未获批
- **THEN** 系统保留原活动基线，展示异常依据及真实任务状态；重复告警不会重复提交同一治理动作，撤权来源停止后续消费
