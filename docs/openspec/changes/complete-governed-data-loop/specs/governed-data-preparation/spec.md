## ADDED Requirements

### Requirement: 专门清洗 Agent 的诊断差异与复检
系统 SHALL 复用 data-cleaning 专家和既有计算器，实现诊断、清洗计划、样本预览、逐行差异、新版本与复检；报告 MUST 展示保留率、删除原因、缺失值及敏感数据处理，并保存来源映射、精确值与列类型，不覆盖原始资产。

#### Scenario: 审阅清洗差异后执行
- **WHEN** 用户确认绑定输入版本和操作方案的清洗计划
- **THEN** 系统生成不可变清洗产物及可追溯差异，复检展示处理前后指标，未通过质量门槛的产物进入隔离状态

#### Scenario: 自定义清洗脚本不能绕过隔离
- **WHEN** 清洗方案需要执行自定义代码但 Sandbox 不可用或策略校验失败
- **THEN** 系统拒绝该步骤，保留诊断和已有产物，不在共享计算服务或宿主直接运行代码

### Requirement: 知识标签建议审核与实际应用
知识打标 Agent SHALL 使用版本化标签方案，输出标签、依据、方法及不确定项并保持待审核；受控发布器 MUST 将已审核内容幂等应用到真实知识元数据与检索过滤索引，保存应用回执和失败状态，不将建议生成或审核状态当作应用成功。

#### Scenario: 审核标签影响实际检索
- **WHEN** 有权限的审核人批准当前方案与内容版本，发布器完成元数据和索引应用
- **THEN** 对该知识资产的标签过滤命中已应用标签，重复应用返回同一回执，不新增重复标签或重复发布

#### Scenario: 修改或部分应用失败
- **WHEN** 人工修改标签内容使旧审核失效，或已批准标签的索引应用失败
- **THEN** 修改后的内容重新待审；部分应用记录为未完成并可幂等重试，读取不得宣称新标签已完整生效

### Requirement: 四类样本建议与独立人工复核
样本标注 Agent SHALL 支持 classification、named_entity、relation 和 question_answer，保留方案、指南、来源版本、方法及审阅版本；MUST 校验标签、Unicode 片段、实体关系和问答证据，建议不得覆盖人工或已审核内容，模型置信度不得替代审核或准确率。

#### Scenario: 四类样本进入审核与发布
- **WHEN** Agent 为四类任务生成符合各自 schema 的建议并由授权审核人完成复核
- **THEN** 系统保存人工纠正及审核证据，仅将当前已批准且与目标 schema 兼容的样本交给版本化数据集发布

#### Scenario: 不确定或未经授权的样本来源
- **WHEN** 建议缺少有效证据、片段或关系非法、存在争议，或尝试自动将私有对话与长期记忆转为共享样本
- **THEN** 系统拒绝非法建议或保留明确的待复核状态，不自动批准、不覆盖人工结果，也不发布未经授权的样本
