## ADDED Requirements

### Requirement: 受管执行输入与能力检查
Runner SHALL 提供 submit、status、cancel、collect 契约，固定已授权不可变输入、镜像摘要、代码摘要和资源策略；工具参数 MUST 禁止宿主路径、任意镜像来源、运行时 socket 和服务凭据，提交使用持久化执行 ID 与幂等键。

#### Scenario: 受管脚本进入执行
- **WHEN** 输入授权有效、镜像及策略获准且 runner 支持全部必需限制
- **THEN** 系统保存执行契约并启动同一幂等执行，返回可用于状态核对和取消的执行 ID

#### Scenario: 执行能力不足
- **WHEN** 请求引用越权输入、传入禁用挂载，或运行时无法落实必需的隔离与限额
- **THEN** 系统拒绝执行并说明原因，不降级为宿主执行或放宽策略

### Requirement: 隔离运行与资源限制
执行环境 MUST 非 root、根文件系统只读、最小 capabilities、限制系统调用，并隔离工作目录；输入只读复制，默认禁网，限制 CPU、内存、进程数、磁盘、时长与输出量。普通 Docker profile SHALL 仅用于已批准的受控环境，多租户不可信代码启用前必须单独验收更强隔离。

#### Scenario: 脚本尝试越权或耗尽资源
- **WHEN** 脚本访问未授权网络、宿主文件、其他任务目录，或突破资源限制
- **THEN** 访问被阻断或任务被终止，系统记录可核对的失败原因，且不得输出完整成功状态

### Requirement: 输出校验与候选资产隔离
collect MUST 校验 manifest、类型、大小、路径、符号链接、归档展开与摘要，日志和错误摘要不得泄露正文或密钥；合格输出 SHALL 仅登记为候选资产，继续经过正常质检与审批，不得直接覆盖原件或活动版本。

#### Scenario: 输出包含非法文件
- **WHEN** 输出含路径逃逸、越界符号链接、超限归档或摘要不匹配
- **THEN** 系统拒绝登记违规输出并保存失败证据，已有业务资产和活动版本保持不变

### Requirement: 取消恢复与隔离目录清理
Runner MUST 在取消或超时后终止整个进程树，按持久执行 ID 核对重启后的孤儿任务；成功、失败和取消均 SHALL 回收任务容器与临时目录，清理只能作用于该执行拥有的资源，失败清理须可重试并可见。

#### Scenario: 成功收集后的清理
- **WHEN** 候选输出已校验并安全登记
- **THEN** runner 保存产物引用及资源消耗后清理运行资源，后续读取通过持久引用完成，不依赖临时目录

#### Scenario: 取消中断后控制器重启
- **WHEN** 取消尚未确认完成时控制器或 runner 重启
- **THEN** 恢复流程核对原执行并完成终止与清理，不启动重复脚本，不误删其他任务资源，并拒绝迟到成功覆盖取消状态
