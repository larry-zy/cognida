## ADDED Requirements

### Requirement: 可审阅的数仓模型版本
数仓建模 Agent SHALL 复用语义模型、指标口径、资产目录和血缘，生成主题域、事实粒度与键、维度关系及原始／明细／汇总／应用层建议；MUST 固定来源版本、列类型、关联基数、口径及转换摘要，校验受限表达式与授权引用。模型建议和预览不得直接执行 DDL、发布语义模型或取得管理员可信 SQL 的权限。

#### Scenario: 事实关联违反声明粒度
- **WHEN** 候选模型的维度键不唯一或关联产生与声明粒度不符的重复聚合
- **THEN** 系统展示冲突及输入／输出差异并阻止该版本发布，不把重复放大的指标作为有效模型结果

### Requirement: 分层转换的有界任务计划
分层加工 SHALL 使用绑定模型版本、输入快照、参数及 SQL／代码摘要的无环有界 DAG，通过统一控制器调用已验收查询适配器与受控操作执行器；MUST 保持外部来源只读，输出仅限已登记且获授权的受管派生空间，自定义脚本遵守 Sandbox。审批和候选校验完成前不得切换活动产物。

#### Scenario: 建模方案尚无可执行目标
- **WHEN** 计划包含依赖环、越权引用、外部原始表写入或未实现的加工目标能力
- **THEN** 系统拒绝执行并保留可审阅诊断，不因查询引擎已接入就开放该引擎写权限，也不以预检成功冒充已加工

#### Scenario: 候选转换失败
- **WHEN** 已获准的受管转换在生成或校验候选时失败或取消
- **THEN** 原活动版本保持可用，系统保留真实阶段和回执，仅清理本任务对象，不先删除旧目标或覆盖原始数据

### Requirement: 增量水位和回填可恢复
增量加工 MUST 明确定义稳定键、分区、水位、更新／删除和迟到处理策略，仅在分区及幂等回执可核对后推进水位；回填 SHALL 固定历史范围与配置并生成可区分的新版本。来源不支持的一致性或删除检测须显式声明，恢复不能重复已提交写入，回填不得改写历史评测及已固定的时点快照。

#### Scenario: 分区提交后进程中断
- **WHEN** 目标分区已提交但水位尚未确认，重启后同一任务再次投递
- **THEN** 系统按确定性操作标识核对该分区，完成回执及水位同步而不重复数据，无法确定时保持待核对且不推进下游

#### Scenario: 历史范围出现迟到记录
- **WHEN** 用户发起回填以纳入迟到记录或修正历史转换
- **THEN** 系统按固定模型及迟到策略生成新候选版本，审核后才切换当前消费；旧评测及历史时点读取保留原快照语义

### Requirement: 版本血缘和变更影响审核
系统 SHALL 在现有上下游查询之上记录实际转换的表列依赖与版本，在变更前展示受影响模型、指标、报告、特征及数据集；MUST 标注未知依赖，执行授权或安全切换所需的关键依赖未解析时阻止发布。模型、输入、SQL 或目标变化须使旧审批失效，实际执行回执与血缘登记齐备后才声明交付成功。

#### Scenario: 已审核模型改变输入或表达式
- **WHEN** 用户或 Agent 修改模型版本的来源、转换表达式或目标
- **THEN** 系统生成新版本和影响预览，要求重新审核，不沿用旧确认直接加工；其他租户依赖不可泄露，未知依赖不能被展示为空影响
