## ADDED Requirements

### Requirement: 查询适配器能力描述
QueryAdapter SHALL 声明引擎及客户端版本、元数据、方言、类型、参数绑定、分页、取消和限额能力，兼容现有 MySQL／PostgreSQL；MUST 支持 SQL 连接与异步作业句柄，不向通用调用方强制暴露数据库连接，不把协议兼容视为完整引擎支持。

#### Scenario: 请求未配置的引擎能力
- **WHEN** 用户选择的引擎缺少凭据、连接配置或所请求的能力
- **THEN** 系统返回明确的不可用状态，不回退查询内部业务库或以其他引擎结果代替

### Requirement: 只读授权与精确结果
数仓查询 MUST 同时执行租户来源授权、服务端最小权限、语句检查及超时限制，禁止写入外部原始数据；结果 SHALL 保留驱动或服务返回的列类型、NULL、DECIMAL 和大整数原值，并携带查询及来源版本证据。

#### Scenario: 查询结果包含高精度值和文本编号
- **WHEN** 已授权查询返回高精度 DECIMAL、大整数和文本编号 00123
- **THEN** Result Store、资产和报告保留精确原值及类型，文本编号不被猜成数值，跨租户获取同一结果句柄被拒绝

### Requirement: 异步作业与取消恢复
适配器 SHALL 持久绑定本地任务与 BigQuery job、Hive 操作或其他服务端执行句柄，记录分页及终态；MUST 支持有界取消、重连核对和超时传播，恢复时不能因响应丢失重复提交作业，取消请求不等于远端已停止。

#### Scenario: 提交后断线并发起取消
- **WHEN** 服务端已接收查询，但客户端未收到结果便断线，随后用户取消任务
- **THEN** 系统依据确定性作业标识查证并取消原作业，保留待核对状态直到远端结果明确，迟到完成事件不覆盖取消决定

### Requirement: 扫描和费用预算
数仓任务 MUST 在执行前固定服务端可执行的扫描、运行时间及费用限制；BigQuery SHALL 使用 dry run 估算与 maximum bytes billed 等实际预算能力，不能以 LIMIT 代替扫描费用上限，无法满足强制预算的查询不得提交。

#### Scenario: 估算费用超过预算
- **WHEN** 查询返回行数较少但预计扫描字节数超过本次预算
- **THEN** 系统在提交计费查询前拒绝执行并显示估算依据；用户修改预算须形成新的明确授权，重试不得自行提高预算

### Requirement: 各引擎独立真实验收
MySQL／PostgreSQL 兼容迁移及 ClickHouse、Doris、StarRocks、Hive、BigQuery 各适配器 MUST 分别在固定版本真实环境验证连接、元数据、语义查询、类型、分页、取消、权限拒绝和报告；Hive SHALL 登记 TLS、认证与身份映射，云查询 SHALL 登记项目、位置及费用上限。

#### Scenario: 尚无某引擎验收环境
- **WHEN** 适配器单测和编译通过，但对应真实集群、账号或云项目未提供
- **THEN** 支持矩阵保持该引擎未验收，不以 MySQL 模拟、其他兼容协议引擎或成功 fixture 宣称该引擎已交付
