# 规格变更说明

本次变更为纯架构重构，**不涉及任何规格级别行为变更**。

## 无新增规格

- 不新增业务能力
- 不改变外部 API 接口
- 不修改请求/响应格式

## 无修改规格

- 业务逻辑行为保持一致
- 外部可观测行为不变
- 只改变内部实现结构

## 重构范围

重构仅影响：
1. 内部目录结构（`internal/` 下的包组织）
2. 导入路径（`link/internal/application/*` → `link/internal/service/*`）
3. 类型转换层（减少不必要的 DTO）

## 验证方式

规格保持不变通过以下方式验证：

1. **外部 API 测试**：所有 HTTP/gRPC 接口的请求/响应格式保持一致
2. **集成测试**：现有集成测试无需修改业务逻辑即可通过
3. **契约测试**：与 Python 服务的 gRPC 接口契约不变
